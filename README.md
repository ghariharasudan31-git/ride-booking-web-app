# 🚖 Ride Booking Web Application

A full-stack ride booking web application built using **Python, Django, HTML, CSS, JavaScript, Bootstrap, and Leaflet.js**.

## ✨ Features

- 📍 Live location detection
- 🗺️ Interactive maps using Leaflet.js
- 🚖 Pickup and drop location selection
- 📌 Route visualization
- 💾 Database integration with Django
- 📱 Responsive user interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Leaflet.js
- MySQL
